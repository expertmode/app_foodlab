# Prompts para imagens IA — Foodlab

## Estilo global (cola este prompt-base ao gerar QUALQUER imagem)

> Estilo: fotografia de comida realista, luz natural suave, fundo neutro/bege claro (#f0f0eb), composição minimalista, profundidade de campo (bokeh suave), cores quentes e naturais, sem texto, sem logos, formato quadrado 1:1, alta qualidade.

Para cada produto há 4 tipos de imagens:

- **`img_main.png`** — produto isolado em fundo transparente (PNG)
- **`img_bg.jpg`** — fundo amplo do banner (paisagem, ingredientes, ambiente)
- **`bottom_img.png`** — imagem secundária do produto, opcional
- **`card1/2/3...jpg`** — uma imagem por característica inovadora
